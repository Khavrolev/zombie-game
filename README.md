# Zombie Defense

Браузерная 2D-игра в духе Plants vs Zombies — обороняй пушку от зомби, зарабатывай деньги и покупай подкрепление. Делается вместе — родитель пишет код, ребёнок участвует в игровых решениях.

Играть можно прямо в браузере, без установки — игра оптимизирована в первую очередь под телефон и планшет в горизонтальной ориентации (на десктопе тоже работает).

## Как играть

- **Пушка** стоит в начале поля. Клик по ней — выстрел очередью из 4 патронов по 4 ближайшим зомби. Перезарядка 10 секунд.
- Зомби идут к пушке произвольными путями и, дойдя до неё, атакуют раз в 5 секунд. После 5 ударов пушка разрушена — и если зомби после этого доберётся до сундука позади неё, уровень проигран.
- Уровень выигран, если все зомби волны уничтожены раньше, чем кто-то дойдёт до сундука.
- **Деньги** падают с неба раз в 30 секунд и выпадают из убитых зомби — их нужно успеть кликнуть за 5 секунд (последние 2 секунды они мигают, предупреждая об исчезновении).
- На деньги можно купить:
  - **Солдата** — ставится в один из слотов вокруг пушки, стреляет по ближайшему зомби раз в 5 секунд, выдерживает 2 удара.
  - **Грабли** — ставятся в любую точку поля, одноразовые: наступивший зомби умирает, грабли исчезают.
- Прогресс (деньги, пройден ли уровень) сохраняется в браузере — можно закрыть вкладку и продолжить позже.

Это MVP: один уровень, один вид зомби. Разные уровни, виды зомби и система наград — в планах.

## Технологии

- **TypeScript** + **[Phaser 3](https://phaser.io/)** — игровое поле и вся игровая логика
- **[Vite](https://vitejs.dev/)** — сборка и dev-сервер
- **[Nanostores](https://github.com/nanostores/nanostores)** — состояние, общее между игрой и интерфейсом
- HTML/CSS поверх canvas (CSS Modules + дизайн-токены) — весь интерфейс вне игрового поля
- **localStorage** — сохранение прогресса
- **[Vitest](https://vitest.dev/)** — юнит-тесты игровой логики
- Деплой на GitHub Pages через GitHub Actions

Подробности архитектуры и игрового сценария — в [`CLAUDE.md`](./CLAUDE.md).

## Запуск локально

```bash
npm install
npm run dev
```

Откроется адрес вроде `http://localhost:5173` — открой его в браузере.

Другие команды:

```bash
npm test         # юнит-тесты
npm run typecheck  # проверка типов
npm run build     # продакшн-сборка в dist/
npm run preview   # локальный просмотр продакшн-сборки
```

## Структура проекта

```
src/
  game/         # Phaser-сцена и игровые сущности (пушка, зомби, солдат, грабли, деньги)
    logic/      # игровые правила как чистые функции (без Phaser) — покрыты тестами
    levels/     # данные уровня (расположение, волны зомби) — отдельно от кода сцены
  ui/           # HTML/CSS-интерфейс поверх canvas (счётчик денег, магазин, экран победы/поражения)
  state/        # общее состояние (nanostores)
  persistence/  # сохранение прогресса в localStorage
```

## Статус

MVP в разработке. Список того, что сознательно оставлено на потом: разные виды и сложность зомби, несколько уровней, система наград (кубки).
