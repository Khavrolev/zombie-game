# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

A browser game built collaboratively by a parent (experienced full-stack developer) and their child (new to using AI tools). The child is a co-author, not just an observer — favor explanations and workflows that help them follow and participate in decisions, not just the parent.

## Технологический стек и архитектура (MVP)

- **TypeScript** + **Phaser 3** — рендеринг игрового поля и вся игровая логика (пушка, солдаты, зомби, грабли, падающие деньги, таймеры перезарядки/деспавна, попадания).
- **Vite** — сборка и dev-сервер; стартовая точка — официальный шаблон Phaser `template-vite-ts`.
- **npm** — пакетный менеджер.
- **Nanostores** — общий state между Phaser-игрой и HTML-UI (деньги, текущий уровень/волна, что куплено, кубки). Обе стороны читают/пишут atoms и подписываются на изменения — Phaser-сцена и DOM-UI не знают друг о друге напрямую.
- **HTML/CSS поверх canvas** для UI (магазин, счётчик денег, экран итогов уровня) — обычные DOM-элементы, не Phaser-объекты.
  - Стили — **CSS Modules** (`*.module.css`) на компонент.
  - Глобальные дизайн-токены (цвета, отступы, радиусы/бордеры) — CSS custom properties в одном файле `tokens.css` на `:root`, импортируется один раз в точке входа. Компонентные стили ссылаются на переменные (`var(--color-primary)`), а не хардкодят значения.
- **localStorage** — persistence прогресса (деньги, уровень, кубки) как сериализованный JSON из nanostores. IndexedDB не нужен: объём данных крошечный (несколько чисел), не требуется ни асинхронность, ни схема/индексация, которые даёт IndexedDB — только лишняя сложность.
- **Vitest** — юнит-тесты игровой логики, не зависящей от рендеринга (выбор ближайшей цели, таймеры перезарядки/исчезновения денег, условия победы/поражения).
- **Деплой** — GitHub Pages через GitHub Actions при пуше в `main`.

Структура репозитория (детали появятся в плане реализации):
- `src/game/` — Phaser-сцена(ы) и игровые сущности (пушка, солдат, зомби, грабли, падающие деньги).
- `src/ui/` — DOM-компоненты HUD/магазина.
- `src/state/` — nanostores-атомы, единый источник правды по деньгам/прогрессу.
- `src/persistence/` — сериализация state в/из localStorage.

## Игровой сценарий (MVP)

2D-игра в духе Plants vs Zombies. Ниже — согласованные правила ядра геймплея. Виды/сложность зомби, состав уровней и волн и формула кубков намеренно не детализированы — это отдельные решения, которые будут приняты позже.

**Поле и юниты**
- Свободное 2D-поле без рядов/полос — зомби идут от края поля к пушке произвольными путями (не по фиксированным дорожкам).
- Пушка одна, стоит в начале игры; за ней (дальше вглубь поля) находится сундук.
- У пушки 5 очков прочности к ближнему бою: каждый зомби, дошедший до неё вплотную, наносит 1 удар. После 5 ударов пушка разрушена, и уцелевшие зомби идут дальше — к сундуку.
- Вокруг пушки — фиксированные слоты (заранее заданные точки на поле), в которые можно поставить купленных солдат.
- **Победа на уровне** — все зомби волны уничтожены раньше, чем кто-то из них дойдёт до сундука.
- **Поражение на уровне** — зомби разрушают пушку и один из них доходит до сундука.

**Стрельба**
- Пушка: клик по пушке → выстрел очередью из 4 патронов, автоматически бьёт по 4 ближайшим зомби (для простых зомби каждый умирает от 1 патрона). Перезарядка 10 сек — повторный клик раньше игнорируется.
- Солдат: клик по солдату → 1 выстрел по ближайшему зомби, зомби умирает. Перезарядка 5 сек.
- Более сильные виды зомби (требующие больше попаданий на убийство) — вне скоупа MVP, добавятся позже без изменения этой механики стрельбы.

**Грабли**
- Покупаются за деньги, ставятся в любую точку свободного поля (в отличие от солдат — без привязки к слотам).
- Одноразовые: наступивший на них зомби умирает, после срабатывания грабли исчезают с поля.

**Деньги**
- Пачка денег падает с неба раз в 30 сек в случайную точку поля.
- Зомби при смерти тоже роняют деньги.
- Любые упавшие деньги нужно кликнуть в течение 5 сек (последние 2 сек — мигают), иначе они пропадают.
- Деньги — единственная валюта в игре, тратится на покупку граблей и солдат.

**Прогресс**
- Прогресс хранится в localStorage браузера, чтобы пользователь мог продолжить с места остановки после перезахода в игру.
- По итогам уровня начисляется 1–5 кубков в зависимости от времени прохождения (формула начисления пока не определена).
